번역 엔진

API 키 없이 바로 동작합니다. MyMemory 번역 + 컨퍼런스 용어 보정.

기본값은 gemini-4-hydrogen입니다. 모델이 없거나 지원이 종료되면(404) 앱이 이 키로 쓸 수 있는 Gemini 4/3 텍스트 모델을 자동으로 찾아 다시 시도합니다.

키는 이 기기 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다. 발표장 와이파이가 불안정하면 기본 엔진이 더 안전합니다.

음성

번역 결과 자동 재생 (TTS)말하면 번역문을 바로 읽어 줍니다
상대방 말도 한국어로 읽기영어 발화를 한국어 음성으로도 재생 (이어폰 권장)
화면 꺼짐 방지사용 중 화면이 유지됩니다(지원 기기)

안드로이드 Chrome 사용 안내

1. 마이크가 안 되면 — 안드로이드 Chrome에서 이 파일을 file://로 직접 열면 보안 정책상 음성 인식(SpeechRecognition) 권한이 차단될 수 있습니다. 이때도 텍스트 입력·퀵문구·음성 출력(TTS)은 그대로 동작합니다.

  1. 파일을 HTTPS 주소에 올려 열기 — 예: GitHub Pages에 index.html로 업로드 후 https://아이디.github.io/저장소/ 접속
  2. 또는 안드로이드 파일 관리자에서 Chrome으로 열기 후 주소창 자물쇠 → 마이크 허용

2. 마이크 없이 말하기 — 입력창을 탭한 뒤 Gboard·삼성 키보드의 마이크 버튼으로 한국어/영어를 받아쓰면, 텍스트 입력과 똑같이 번역·음성 출력됩니다.

3. 시끄러운 전시장 — 마이크 버튼 대신 퀵문구와 텍스트 입력이 가장 안정적입니다. 말풍선의 확대 보기로 화면을 상대에게 보여 주세요.

4. 인터넷 — 번역은 온라인 API를 사용합니다. 와이파이가 끊기면 말풍선에 재시도 버튼이 나타나고, 퀵문구는 네트워크 없이도 그대로 표시·재생됩니다.

데이터

대화 내용은 이 브라우저 메모리에만 있고, 새로고침하면 사라집니다. 퀵문구는 이 기기에 저장되며, 초기화하면 기본 8개로 돌아갑니다.

사용법 · 도움말

3초 사용법

  1. 🇰🇷 한국어로 말하기 — 탭하고 한국어로 말하면 영어 번역 + 영어 음성
  2. 🇺🇸 영어로 듣기 — 탭하고 상대에게 말을 걸면 영어 인식 + 한국어 번역
  3. 말풍선 🔊 다시 듣기 · 확대 로 상대에게 화면 보여주기
  4. 연속 대화를 켜면 내 말 → 상대 말 → 내 말 순서로 자동 전환됩니다
  5. ⚡ 현장 퀵문구는 ✎ 편집에서 문구·순서를 바꾸고 새로 추가할 수 있습니다(한국어만 적고 자동 영작 가능)

현장 팁

  • 한 번에 한 문장씩, 20초 이내로 말하면 인식률이 가장 좋습니다.
  • 주변 소음이 크면 마이크를 입 가까이(10~15cm) 대고 말하세요.
  • 전문용어(국가데이터처·SDC·폐쇄망·비식별화·에이전틱 AI)는 내장 사전으로 자동 보정됩니다.
  • 상대의 말을 못 알아들었으면 "Could you speak a little more slowly, please?" 퀵문구를 쓰세요.
  • 중요한 숫자·고유명사는 텍스트 입력으로 확인하면 오역을 줄일 수 있습니다.

안드로이드에서 마이크가 안 될 때

file://로 연 경우 마이크 권한이 막힐 수 있습니다. 텍스트 입력 + 키보드 음성입력(Gboard 마이크)으로 그대로 사용할 수 있고, HTTPS 주소(GitHub Pages 등)로 열면 마이크도 동작합니다. 자세한 순서는 설정 → 안드로이드 Chrome 사용 안내에 있습니다.

번역 품질

기본 엔진은 MyMemory(API 키 불필요)로 가볍게 동작하고, 설정에서 OpenAI·Gemini 키를 넣으면 컨퍼런스 통역 전용 프롬프트로 문장이 훨씬 자연스러워집니다.

현장 퀵문구 편집

탭하면 바로 영어로 표시·재생되는 문구입니다. ↑↓로 순서를 바꾸고, 이 기기에 자동 저장됩니다.
