# 한·영 동시통역 대화앱

SAS Innovate 2027 현장용 한·영 대화형 동시통역 모바일 웹앱입니다.

- **💬 1:1 대화 모드** — 한국어로 말하기 ↔ 영어로 듣기 양방향 대화·퀵문구·큰 글씨 보기
- **🎬 실시간 자막 모드** — 강연·외국인 대화를 고대비 자막으로: 원문(작게) + 번역(크게)이 문장 단위로 쌓이며 자동 스크롤, 인식 중인 말 실시간 미리보기
- 자막 듣기 언어: 영어(EN·기본) · 일본어(JA) · 중국어(ZH) · 한국어(KO, 영어로 번역) · 자동 감지(Groq Whisper `whisper-large-v3-turbo`, Groq 키 필요)
- 자막 글자 크기(보통/크게/특대) · 자막 비우기 · 전체 복사 · 실행 중 화면 꺼짐 방지(WakeLock)
- 브라우저 내장 음성인식·음성합성 기반(기본 엔진), 설정에서 OpenAI/Gemini/Groq API 키를 넣으면 AI 통역 모드 사용 가능 — 자막 모드도 같은 엔진으로 번역
- Groq은 카드 등록 없이 무료로 키를 발급받아(하루 1,000회) 가장 빠른 응답으로 통역합니다. 기본 모델 `openai/gpt-oss-120b`
- API 키는 사용하는 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 사용

https://sogic8-web.github.io/kr-en-interpreter/

휴대폰 크롬에서 위 주소를 연 뒤 **홈 화면에 추가**하면 앱처럼 실행되며, HTTPS 주소이므로 마이크 권한을 바로 사용할 수 있습니다.
