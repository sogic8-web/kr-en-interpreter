# 한·영 동시통역 대화앱

SAS Innovate 2027 현장용 한·영 대화형 동시통역 모바일 웹앱입니다.

- **💬 1:1 대화 모드** — 한국어로 말하기 ↔ 영어로 듣기 양방향 대화·퀵문구·큰 글씨 보기
- **🎬 실시간 자막 모드** — 강연·외국인 대화·뉴스 방송을 고대비 자막으로: 원문(작게) + 번역(크게)이 문장 단위로 쌓이며 자동 스크롤, 인식 중인 말 실시간 미리보기
- 자막 듣기 언어: 영어(EN·기본) · 일본어(JA) · 중국어(ZH) · 한국어(KO, 영어로 번역) · 자동 감지(Groq Whisper `whisper-large-v3-turbo`, Groq 키 필요)
- 자막 글자 크기(보통/크게/특대) · 자막 비우기 · 전체 복사 · 실행 중 화면 꺼짐 방지(WakeLock)
- 브라우저 내장 음성인식·음성합성 기반(기본 엔진), 설정에서 OpenAI/Gemini/Groq API 키를 넣으면 AI 통역 모드 사용 가능 — 자막 모드도 같은 엔진으로 번역
- Groq은 카드 등록 없이 무료로 키를 발급받아(하루 1,000회) 가장 빠른 응답으로 통역합니다. 기본 모델 `openai/gpt-oss-120b`
- API 키는 사용하는 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 🎙 CNN 뉴스·TV/PC 스피커·강연장 수음 (2026-11-22 개선)

- **마이크 음량 미터** — 자막 모드 상태 줄에 실시간 음량 막대를 넣어 마이크가 실제로 소리를 잡고 있는지 바로 확인합니다. Whisper(자동 감지) 모드는 스트림을 `AnalyserNode`로 직접 분석하고, Web Speech 모드는 같은 마이크를 두 번 열면 안드로이드에서 충돌하므로 `MIC / 수음 / 말소리 / 무음` 배지로 상태를 보여 줍니다.
- **연속 발화 자동 끊기 번역** — CNN 앵커처럼 쉼 없이 말해 `isFinal`이 오지 않아도, 인식 중인 문장(interim)이 80자(영어 기준) 이상 쌓이거나 3.5초 넘게 확정되지 않으면 앞부분을 즉시 번역해 자막으로 올립니다. 이미 올린 앞부분은 기억해 두었다가 뒤따르는 확정 결과에서 덜어내 중복 번역이 생기지 않습니다.
- **무응답 자동 복구** — 8초 넘게 인식 결과가 끊기면 인식을 `abort()` 하고 새로 시작해, 안드로이드 크롬에서 `continuous` 인식이 조용히 멈추는 문제를 완화했습니다.
- **스피커 수음 품질** — `echoCancellation:false`, `noiseSuppression:false`, `autoGainControl:true`로 마이크를 열어 TV·PC·강연장 스피커 소리를 브라우저가 "배경 잡음"으로 지우지 않게 했습니다.
- **무음 청크는 API 호출 생략** — 4~6초 청크의 RMS 평균이 무음이면 Whisper에 보내지 않아 "Thank you", "MBC 뉴스" 같은 헛번역이 생기지 않습니다. 말이 이어지는 중에는 쉬는 지점에서 청크를 끊어 단어 잘림을 줄입니다.
- 그 밖에 대기 화면에 "같은 폰에서 재생 중인 영상 소리는 안드로이드 정책상 잡히지 않는다"는 안내를 넣었고, Groq 키가 있으면 `🤖 자동 감지(Groq Whisper)` 전환 안내 줄을 보여 줍니다.
