# 다국어 동시통역 앱 (한국어 ↔ 8개 언어)

SAS Innovate 2027 현장용 **다국어** 동시통역 모바일 웹앱입니다. 한국어를 영어·일본어·중국어·스페인어·프랑스어·독일어·베트남어·태국어로, 또는 그 반대로 양방향 통역합니다.

- **💬 1:1 대화 모드** — 상대 언어를 고르면 버튼·음성인식·음성출력·번역이 그 언어로 바뀌는 양방향 대화·퀵문구·큰 글씨 보기
- **🎬 실시간 자막 모드** — 강연·외국인 대화·뉴스 방송을 고대비 자막으로: 원문(작게) + 번역(크게)이 문장 단위로 쌓이며 자동 스크롤, 인식 중인 말 실시간 미리보기
- 자막 듣기 언어: 영어 · 일본어 · 중국어 · 한국어(영어로 번역) · 스페인어 · 프랑스어 · 독일어 · 베트남어 · 태국어 9개 + 자동 감지(Groq Whisper `whisper-large-v3-turbo`, Groq 키 필요)
- 자막 글자 크기(보통/크게/특대) · 자막 비우기 · 전체 복사 · 실행 중 화면 꺼짐 방지(WakeLock)
- **🎧 자막 음성 듣기(이어폰 TTS)** — 번역이 끝난 문장을 이어폰으로 자동 재생, 자막 한 줄을 탭하면 그 문장만 다시 듣기
- 브라우저 내장 음성인식·음성합성 기반(기본 엔진), 설정에서 OpenAI/Gemini/Groq API 키를 넣으면 AI 통역 모드 사용 가능 — 자막 모드도 같은 엔진으로 번역
- Groq은 카드 등록 없이 무료로 키를 발급받아(하루 1,000회) 가장 빠른 응답으로 통역합니다. 기본 모델 `openai/gpt-oss-120b`
- API 키는 사용하는 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 🌍 다국어 지원 (2026-11-22 확장)

### 공통 언어 테이블

두 모드가 **하나의 언어 표(`LANGS`)** 를 함께 씁니다. 언어별로 앱 키·한글 이름·국기·BCP-47 코드(음성인식·TTS)·MyMemory 코드를 한 곳에서 관리합니다.

| 언어 | 키 | 음성인식·TTS (BCP-47) | MyMemory |
|---|---|---|---|
| 🇺🇸 영어 | `en` | `en-US` | `en` |
| 🇯🇵 일본어 | `ja` | `ja-JP` | `ja` |
| 🇨🇳 중국어 | `zh` | `zh-CN` | `zh-CN` |
| 🇪🇸 스페인어 | `es` | `es-ES` | `es` |
| 🇫🇷 프랑스어 | `fr` | `fr-FR` | `fr` |
| 🇩🇪 독일어 | `de` | `de-DE` | `de` |
| 🇻🇳 베트남어 | `vi` | `vi-VN` | `vi` |
| 🇹🇭 태국어 | `th` | `th-TH` | `th` |
| 🇰🇷 한국어 | `ko` | `ko-KR` | `ko` |

### 💬 1:1 대화 모드

- **상대 언어 선택** — 대화 화면 위쪽 `상대 언어` 드롭다운(기본 영어). 고른 값은 `localStorage`에 저장되어 다음에 열 때도 유지됩니다.
- **한 번에 바뀌는 것** — 하단 버튼(`🇯🇵 일본어로 듣기` / `탭 → 말하면 일본어로`), 음성인식 언어(`ja-JP`), TTS 음성(`ja-JP`), 말풍선 라벨(`한국어 → 일본어`), 입력창 안내 문구, 퀵문구 안내, 빈 화면 안내.
- **텍스트 입력 자동 판별** — 한글이 들어 있으면 `한국어 → 상대 언어`, 없으면 `상대 언어 → 한국어`로 번역합니다. 방향 버튼(`자동 · 한→JA`)을 누르면 `자동 → 한국어→상대 → 상대→한국어` 순으로 직접 지정할 수 있습니다.
- **현장 퀵문구** — 상대 언어가 영어면 저장된 영문을 그대로 즉시 표시·재생. 영어가 아니면 **한국어 뜻(없으면 영문 문장)을 현재 번역 엔진으로 그 언어로 번역**해 말풍선 + TTS로 바로 출력합니다. 기본 8개 문구에는 한국어 뜻이 들어 있어 8개 언어 어디로든 자연스럽게 번역됩니다.
- **큰 글씨 모달·다시 듣기** — 말풍선마다 번역 언어를 기억하므로, 상대 언어를 바꾼 뒤에도 예전 말풍선은 원래 언어로 다시 읽어 줍니다.

### 🎬 실시간 자막 모드

- **2줄 × 5칸 언어 칩** — 390px 폭에서 가로 넘침·줄깨짐 없이 10개(9개 언어 + 🤖 자동)가 모두 보입니다. 1줄: 영어·일본어·중국어·한국어·자동 / 2줄: 스페인어·프랑스어·독일어·베트남어·태국어.
- **번역 엔진 연결** — 기본(MyMemory)·Groq·Gemini·OpenAI 모두 선택한 언어 쌍으로 번역하고, 중국어는 MyMemory 규격에 맞춰 `zh-CN`으로 보냅니다.
- **🎧 듣기 TTS** — 번역문 언어의 BCP-47 코드로 재생합니다. 일본어·스페인어 강연을 들으면 한국어(`ko-KR`) 자막을 읽고, 한국어를 들으면 영어(`en-US`) 자막을 읽습니다.
- **음성인식 미지원 언어 안내** — 기기 크롬이 해당 언어 인식을 지원하지 않으면(`language-not-supported`) 무한 재시도 대신 "🤖 자동 감지(Groq Whisper)를 쓰라"는 안내를 띄웁니다.

## 🎧 자막 음성 듣기 — 이어폰 TTS (2026-11-22 추가)

- **🎧 듣기 ON/OFF 토글** — 자막 모드 상단 줄(글자 크기 버튼 옆)에 있습니다. 설정은 기기 브라우저(localStorage)에 저장되어 다음에 열 때도 유지됩니다. 켜면 "이어폰 착용 시 강연 소리와 겹치지 않고 실시간 통역을 들을 수 있습니다" 안내가 뜨고, 목소리 확인용 안내 한 문장을 읽어 줍니다.
- **번역 완료 → 자동 재생** — `🎧 듣기 ON` 이면 번역이 끝난 문장을 `speechSynthesis`로 읽습니다. 속도는 설정의 말하기 속도(`ttsRate`)를 따릅니다.
- **지연 방지(최신성 유지)** — 강연이 빨라 자막이 몰릴 때 음성이 밀리지 않도록 대기열은 **최대 2문장**입니다. 넘치면 오래된 미재생 문장부터 건너뛰고 최신 문장 위주로 재생합니다(현재 읽는 문장은 끝까지 읽음).
- **즉시 중단** — `🎧 듣기 OFF`, `자막 멈춤`, `자막 비우기`, `💬 1:1 대화` 탭 전환 시 `speechSynthesis.cancel()`과 대기열 비우기가 바로 실행됩니다.
- **개별 문장 다시 듣기** — 자막 목록의 문장을 탭하면 그 문장의 번역음만 1회 다시 읽습니다(듣기 OFF 상태에서도 동작).
- 1:1 대화 모드의 TTS·연속 대화 자동 전환과는 별도 경로라 서로 간섭하지 않습니다.
- **이어폰 사용 권장** — 스피커로 들리면 마이크가 그 통역 음성을 강연 소리로 다시 인식할 수 있습니다(토글을 켤 때 같은 안내가 뜨기도 합니다).

## 🎙 CNN 뉴스·TV/PC 스피커·강연장 수음 (2026-11-22 개선)

- **마이크 음량 미터** — 자막 모드 상태 줄에 실시간 음량 막대를 넣어 마이크가 실제로 소리를 잡고 있는지 바로 확인합니다. Whisper(자동 감지) 모드는 스트림을 `AnalyserNode`로 직접 분석하고, Web Speech 모드는 같은 마이크를 두 번 열면 안드로이드에서 충돌하므로 `MIC / 수음 / 말소리 / 무음` 배지로 상태를 보여 줍니다.
- **연속 발화 자동 끊기 번역** — CNN 앵커처럼 쉼 없이 말해 `isFinal`이 오지 않아도, 인식 중인 문장(interim)이 80자(영어 기준) 이상 쌓이거나 3.5초 넘게 확정되지 않으면 앞부분을 즉시 번역해 자막으로 올립니다. 이미 올린 앞부분은 기억해 두었다가 뒤따르는 확정 결과에서 덜어내 중복 번역이 생기지 않습니다.
- **무응답 자동 복구** — 8초 넘게 인식 결과가 끊기면 인식을 `abort()` 하고 새로 시작해, 안드로이드 크롬에서 `continuous` 인식이 조용히 멈추는 문제를 완화했습니다.
- **스피커 수음 품질** — `echoCancellation:false`, `noiseSuppression:false`, `autoGainControl:true`로 마이크를 열어 TV·PC·강연장 스피커 소리를 브라우저가 "배경 잡음"으로 지우지 않게 했습니다.
- **무음 청크는 API 호출 생략** — 4~6초 청크의 RMS 평균이 무음이면 Whisper에 보내지 않아 "Thank you", "MBC 뉴스" 같은 헛번역이 생기지 않습니다. 말이 이어지는 중에는 쉬는 지점에서 청크를 끊어 단어 잘림을 줄입니다.
- 그 밖에 대기 화면에 "같은 폰에서 재생 중인 영상 소리는 안드로이드 정책상 잡히지 않는다"는 안내를 넣었고, Groq 키가 있으면 `🤖 자동 감지(Groq Whisper)` 전환 안내 줄을 보여 줍니다.

## 호환성

- 저장 키(`kim_sdc_interpreter_v1`)와 퀵문구 키(`kim_sdc_quick_phrases_v1`)는 그대로라, 예전에 저장한 설정·퀵문구가 그대로 이어집니다. 새 항목은 `partnerLang`(상대 언어, 기본 `en`) 하나입니다.
- 예전 자막 언어 값(`en`/`ja`/`zh`/`ko`/`auto`)도 그대로 유효합니다.
